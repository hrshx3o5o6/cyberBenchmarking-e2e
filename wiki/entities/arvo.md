# ARVO

Packages OSS-Fuzz vulnerabilities into reproducible Docker images (Mei et al., 2024). Provides infra, not agent tasks or functional tests; not continuously updated, so CyberGym-E2E builds directly from OSS-Fuzz too ([[wiki/sources/cybergym-e2e]], §3.1, step 1). Kind: dataset.
